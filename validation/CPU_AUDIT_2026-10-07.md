# CardiVex 0.4.0 CPU audit — 2026-10-07

Baseline: `0b3dfa358443dfff8f25dbf9594f8d461eddd17f` (0.3.0).
The baseline's 141 tests passed. This audit added independent numerical references,
invalid-input and integrity regressions, and fresh empirical reproduction.

## Verified results

- 188 tests passed locally on Python 3.12; statement coverage 90.03% (85% CI minimum).
- Exact two-group permutation tests matched SciPy on ten independent seeded cases.
  Classification accuracy, balanced accuracy and macro F1 matched scikit-learn.
- Source distribution and wheel built successfully. A clean environment installed the
  wheel with no runtime dependencies and ran the CLI outside the repository.
- Three original GEO archives downloaded and their SHA-256 hashes verified.
- GSE144424: 84 RNA observations collapsed to 60 subject/timepoint records from
  15 biological subjects. Temporal LOSO now fits normalization exclusively on the
  other 14 subjects before fitting its predictor. Every fold exports its fit IDs,
  centers and scales so separation can be audited.
- Corrected temporal MAE: 0.061354; persistence MAE: 0.070862. Subject-paired mean
  improvement: 0.009508; bootstrap 95% interval [-0.005733, 0.021684]. Twelve of
  fifteen folds improve. The interval includes zero: temporal superiority is unproven.
- Fold-normalized centroid classification: 65% four-class accuracy and 90% hypoxia
  versus other accuracy. Delta features require the held-out subject's normoxia
  measurement as a test-time covariate. This is a paired experimental classification
  task, not diagnosis from an isolated unknown sample.
- GSE234907: six samples (3 vs 3), transformed without external refitting using
  development-only GSE144424 artifact `27a6554942da99ba`. Exact per-domain tests
  enumerate 20 assignments and cannot reach a two-sided p-value below 0.1.
- GSE144423: 56 RNA/ATAC matched subject/condition pairs. Raw mean peak counts
  measure library-depth QC, not normalized biological accessibility or functional
  multimodal validity. No peak-to-gene mapping or methylation analysis was performed.
- Frozen suite normalization and calibration now exclude the same three subjects
  (18855, 18870, 19128). Its updated calibration artifact is `6d1f425d9b934d26`.

## Corrected defects

1. LOSO preprocessing leaked test-subject information into normalization in the
   temporal, classification and frozen-suite pipelines. All three runners now fit
   transforms within the relevant development split.
2. The external directional comparison used an arbitrary positive placeholder vector.
   It now explicitly reports no validated direction transfer and supplies exact
   descriptive permutation statistics instead.
3. Permutation-test absolute tie tolerance changed p-values when measurement units
   changed. Relative tolerance preserves scale invariance. Non-finite input and
   enumeration above 100,000 assignments fail explicitly.
4. Balanced accuracy incorrectly averaged over predicted-only classes. It now
   averages recall over classes present in observations; macro F1 retains union labels.
5. Non-finite counts, duplicate/version-colliding genes, zero-count libraries,
   malformed external gene rows, invalid gene modules and scaler parameters are
   rejected. Module scoring retains only module expression while still computing
   library sizes over all genes.
6. Mutable frozen parameters could retain a stale artifact ID. Every application
   now verifies the payload hash, parameter completeness and finite raw scores.
7. Missing domains were silently imputed as zero. Distances/calibration require
   aligned domains. Unmatched modality detection/recovery scores now serialize as
   null; overall recovery uses comparable modalities or the aligned domain profile.
8. Negative/NaN/infinite or uninformative weights, invalid state times and duplicate
   trajectory timestamps could yield plausible-looking outputs. They now fail.
   A single observation returns the full [0,1] uncertainty range. Normal-approximation
   bands for multiple observations remain descriptive, not validated coverage guarantees.
9. CLI inputs now reject non-numeric/non-finite features before model execution;
   JSON serialization rejects non-finite outputs and stringified key collisions.
10. CI formerly skipped failed/mismatched downloads and could consume tracked stale
    reports. It now requires all three verified archives, generates outputs into a
    fresh temporary directory, verifies their contents and uploads those fresh results.

## Reproduce on CPU

```bash
python -m pip install -e '.[test,reference]'
python -m pytest --cov=cardivex --cov-fail-under=85
python scripts/download_validation_data.py
python scripts/run_full_validation.py --output-dir validation/reproduction
python scripts/run_improved_classification.py --output-dir validation/reproduction
python scripts/run_next_validation_bundle.py --output-dir validation/reproduction
python scripts/verify_real_validation.py validation/reproduction
python -m build
```

historical evidence and retain their original content; use the corrected 0.4 outputs
for current comparisons. Sources and pinned hashes are recorded in

## Remaining scientific limits

This establishes software correctness for the tested contracts and reproducibility
of these small public-data slices. It does not establish clinical validity,
causal recovery, realistic unseen challenges, or generalization across institutions.
RNA modules are curated proxy features, their mapping and cross-study platform
comparability require biological review, and the external comparison is small and
biologically different from the hypoxia training contrast. Bootstrap intervals and
normal bands require appropriate independent sampling units and cannot create
information beyond these datasets. Historical exploratory/gene-selection scripts
outside the three audited runners were not comprehensively revalidated. There are
also existing unused-import/style findings outside this change; no lint-clean claim
is made. The product is improved and reproducible within this scope, not perfect or
fully biologically validated.
